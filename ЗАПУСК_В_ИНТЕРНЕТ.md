# Выложить приложение в интернет — по шагам «копируй и делай»

Так друзья откроют сайт **с телефона**, твой компьютер может быть **выключен**.

---

## 1) Установи Git (один раз)

1. Открой в браузере: **https://git-scm.com/download/win**
2. Скачай установщик → ставь всё «Далее» по умолчанию.

---

## 2) Зарегистрируйся на GitHub (один раз)

1. **https://github.com/signup**
2. Придумай логин, пароль, подтверди почту.

---

## 3) Создай пустой репозиторий

1. Зайди: **https://github.com/new**
2. **Repository name:** например `AI_PPTX_PRO`
3. Выбери **Public**
4. **НЕ включай** галочки «Add README» / «.gitignore» (папка у тебя уже есть).
5. Нажми **Create repository**.

На странице GitHub появится подсказка с URL — запомни свой логин и имя репозитория.

---

## 4) Загрузи проект с компьютера

1. В проводнике открой папку **`AI_PPTX_PRO`** (где лежит `main.py`).
2. В адресной строке проводника набери **`powershell`** и нажми Enter — откроется PowerShell **уже в этой папке**.
3. Выполни команды **по очереди** (скопируй целиком блок, потом исправь только URL):

```powershell
git init
git add .
git commit -m "upload AI PPTX PRO"
git branch -M main
```

4. Подключи GitHub (подставь **свой логин** и **имя репозитория**):

```powershell
git remote add origin https://github.com/ТВОЙ_ЛОГИН/AI_PPTX_PRO.git
git push -u origin main
```

**Если спросит логин/пароль:**  
пароль GitHub **не подойдёт**. Нужен **токен**:

- GitHub → **Settings** → **Developer settings** → **Personal access tokens** → создай токен с правом **repo** → вставь его вместо пароля.

---

## 5) Подключи Streamlit Cloud (бесплатно)

1. Открой **https://share.streamlit.io/**
2. **Sign in** через GitHub → разреши доступ.
3. **Create app** / **New app**:
   - **Repository:** твой `AI_PPTX_PRO`
   - **Branch:** `main`
   - **Main file path:** `main.py`
4. Нажми **Deploy**. Подожди 1–3 минуты.

Появится ссылка вида **`https://....streamlit.app`** — это и есть твой сайт.

---

## 6) Вставь ключ Gemini (обязательно)

1. В Streamlit: твоё приложение → меню **⋮** (справа сверху) → **Settings** → **Secrets**.
2. Открой на компьютере файл **`secrets_for_streamlit_cloud.toml`** из этой папки — там шаблон.
3. Вставь **свой** ключ вместо текста в кавычках (ключ бери в **https://aistudio.google.com/** → Get API key).
4. Сохрани **Save**. Приложение перезапустится само.

Pexels / Unsplash можно оставить пустыми — картинки тогда ищутся через **Wikimedia**.

---

## 7) Дать ссылку друзьям

Скопируй адрес **`....streamlit.app`** и отправь — открывают в браузере на телефоне.

---

## Если что-то не получилось

- Ошибка при `git push` — проверь токен GitHub и правильность ссылки `origin`.
- Приложение в Streamlit «падает» — зайди в **Manage app** → **Logs** и пришли текст ошибки.
- Локально всё как раньше: дважды кликни **`ЗАПУСТИТЬ_У_СЕБЯ.bat`** или `python -m streamlit run main.py`.

---

**Важно:** файл **`.env`** с ключами в GitHub **не попадёт** (он в `.gitignore`). В облаке ключи только через **Secrets** на сайте Streamlit.
